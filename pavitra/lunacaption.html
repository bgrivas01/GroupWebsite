LunaCaption

A Windows desktop app that writes captions for a whole batch of images on your own computer, lets you edit them, and exports the results.

Overview

LunaCaption turns a folder of photos into written captions. It runs the pretrained Salesforce BLIP base model locally, so images are never sent to an online captioning service, and it works offline once the model (about 1 GB) has been downloaded.

The captions are drafts: you can review every one, fix it, and then export the whole batch for a dataset, an archive, or alt text.

What it does

  • Add individual images, or open a whole folder with its subfolders.
  • Choose short, standard, or long captions.
  • Runs on the CPU by default, with an optional CUDA (GPU) mode that falls back to the CPU.
  • Preview each image next to its caption, edit it, restore the original AI text, or copy it.
  • Save a session and reopen it later. Sessions store image paths, not copies, and can relink images that were moved. A recovery copy is kept automatically.
  • Export to CSV or to JSON, which also records the original captions and the model revision.
  • Keyboard shortcuts for adding images, generating, exporting, saving, opening, and cancelling.

How it works

  1. Add images or open a folder.
  2. Pick a caption length and click Generate captions.
  3. Select a row to preview the image and edit its draft caption.
  4. Export the batch to CSV or JSON.

Built with

  • Python 3.11–3.13
  • Tkinter
  • Salesforce BLIP (Hugging Face)
  • PowerShell setup scripts
  • pytest
  • ruff

Notes

The project has 310 automated tests. Caption quality was measured with BLEU and ROUGE scores on a 50-image local sample; a human review of the captions is still to come.

LunaCaption uses BLIP as a pretrained model and does not claim to have trained it. The repository still uses the project's earlier name, LumaCaption.
