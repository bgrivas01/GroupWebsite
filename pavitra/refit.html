Overview

RefIt is a place to keep art references in one spot. Every account gets a private library on the server, with tools for organizing it: named folders, your own tags, favorites, and search.

The public home page shows a sample collection of public-domain artwork from the Art Institute of Chicago. Creating an account starts an empty, private library.

What it does

  • Upload several images at once, drag files onto the page, or paste an image from the clipboard.
  • Organize references into named folders, rename folders, and move images between them.
  • Create custom tags and search by title, notes, or #tag.
  • Mark favorites, download untouched originals, and move images to a Trash you can restore from.
  • Switch between light and dark themes; the choice is remembered in your browser.
  • Browse a responsive masonry gallery with thumbnails and pages of results.

It accepts PNG, JPEG, WebP, GIF, BMP, and TIFF files up to 25 MB and 40 megapixels each, with no limit on how many images you keep.

How it works

RefIt is a Django app. Accounts, folders, and tags live in a SQLite database, and the original images and their thumbnails are stored on the server's disk. Images are only served through routes that check you're logged in and own the image, so nobody else can open your uploads by guessing a link.

A small amount of plain JavaScript handles uploading, drag-and-drop, pasting, and theme switching. Everything else is server-rendered HTML and CSS.

Built with

What's next

RefIt runs locally today. It needs a Python host with a persistent disk to go online, since GitHub Pages can't run a Python server. Color picking and palette extraction, password recovery, and email verification are planned for later versions.
